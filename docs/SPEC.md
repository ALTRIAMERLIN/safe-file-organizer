二、目标与范围
面向需要整理办公文件的用户，完成“选择目录→配置规则→预览→明确执行→查看日志→撤销”。主要展示批量文件自动化、可解释预览和可靠恢复能力。
v1 支持 Windows 10/11、本机磁盘普通目录、普通文件、单用户单任务。Python 3.11+，核心逻辑与界面分离；推荐 tkinter 本地桌面界面加 CLI，实际在 Windows 验收。界面及作品集文案英文，提供中文启动说明。无需账号、服务器或外部 API。
不支持跨卷移动、网络共享、云盘同步目录中的并发修改、目录重命名、符号链接/junction、模糊匹配、内容识别、删除重复文件、压缩、后台监控、自动定时整理。不得承诺恶意并发环境或突然断电下的完全事务安全。
只更改文件位置和名称，不改文件字节内容。默认不递归；可显式启用递归。跳过隐藏/系统文件、链接及应用状态目录，显示跳过原因。源路径或祖先涉及链接/junction 时拒绝处理；硬链接文件拒绝纳入操作并说明。

三、功能定义
F01 扫描：选择一个源根目录，可按扩展名筛选，大小写不敏感。展示相对路径、大小、修改时间、纳入/跳过状态。读取失败列出明确错误，不能静默忽略。
F02 重命名：顺序固定为“文件主名文字替换→前缀/后缀→可选编号”。只支持字面量、大小写敏感替换，不支持正则；空查找串非法。最后一个点之后视为扩展名，保留原扩展名及大小写；无扩展名文件保留无扩展名。
编号从1开始，默认3位，超出位数自然增长，不截断。最终主名为 prefix + replaced_stem + suffix + 可选的 '_' + 编号。编号按纳入文件的原始相对路径排序（casefold 为第一排序键，原字符串为第二键），全批次编号，不按目录重启。空规则合法，为 no_op。
F03 分类：不分类 / 按扩展名 / 按修改年月，三选一。分类目标固定为源根目录下 Organized/，排除扫描此子树；若它是链接则拒绝。按扩展名使用小写扩展名目录，无扩展名进入 no_extension；按修改年月使用文件 mtime 的 UTC 年月 YYYY-MM，并在界面标明 UTC，不使用创建时间或 EXIF。分类时不保留原子目录层级，重名因此必须被识别。仅重命名时保留原父目录。
F04 预览：逐项列出原相对路径、新相对路径、动作 rename/move/move_and_rename/no_op、状态 ready/conflict/skipped、原因。展示扫描总数和各状态数量，可导出 UTF-8 CSV 和 JSON 计划。计划包含 schema_version、plan_id、根目录、规则、来源大小/mtime_ns/SHA-256、目标、状态及计划摘要。计划文件保存到应用状态目录，不写入源目录。
同一输入快照与规则产生相同映射；plan_id 和生成时间可不同。计划是数据，不允许加载任意命令。导入计划时校验格式、根目录边界、来源和目标、摘要及当前文件状态；摘要只检测意外变更，不宣称防篡改认证。
F05 冲突：目标存在、多个源映射到同一目标、仅大小写改名、非法 Windows 名称、路径越界、父路径为文件、目标为另一待移动源，都阻止整个计划执行。包括交换/循环改名，不自动加后缀、不覆盖、不偷偷跳过。casefold 后比较路径，保守拒绝大小写冲突。检查设备保留名、非法字符、末尾点/空格和当前平台路径限制。预览不创建目标目录、不改变源文件。
F06 执行：界面必须先有有效预览，用户点击 Apply 后确认文件数及根目录。改动规则或目录使旧预览失效。CLI 分成 plan/apply 两步；apply 必须显式指定计划并给出 --yes，无计划不得直接扫描并执行。
执行前全批次复检源文件身份/内容、目标不存在、路径合法、同卷、日志目录可写；失败时零文件移动。逐项移动前再次检查，使用 Windows 上不会覆盖已存在目标的移动机制，禁止用可覆盖目标的 replace。检测到文件变化、占用、权限异常或新冲突即停止后续操作，不自动继续。
正常完成和部分失败均输出每项结果及计数。部分失败保留已成功结果，并允许撤销；不默认自动回滚。无变更计划成功返回，但不产生可撤销动作。成功后来源→目标的 SHA-256 一致。程序不删除用户文件；仅允许清理本次创建且仍为空的目录。
F07 日志与恢复：应用状态保存在用户应用数据目录；测试可覆盖为临时目录。每批有 run_id、计划快照、逐操作追加日志和汇总。每次移动前持久写入 intent，成功后写 done；日志写失败不得发起下一项移动。状态至少区分 planned/running/completed/partial_failed/interrupted/undone/undo_partial_failed/needs_review。
同一根目录的所有本工具实例共用排他锁，禁止两个执行/撤销并发；采用进程退出后释放的锁，不能仅靠“存在锁文件”。
下次启动发现中断批次，先对照日志及源/目标位置、身份与内容；仅当状态可唯一判定时归类为已完成或未执行。两边都有、两边都无、身份不符或内容不符均 needs_review，保持文件原状并给出人工恢复路径。不得因没有 done 就认定未移动。恢复只核对并提供撤销，不自动继续未完成的批量移动。
F08 撤销：v1 只支持同一根目录最近一个尚未撤销的批次，含部分失败/中断中已确认成功的项；按成功操作逆序恢复。撤销前全批检查当前目标身份与SHA-256、原位置空闲、所有路径仍在根内。发现外部修改、替换、丢失或原位置占用，整次撤销不启动并说明具体项，禁止覆盖。撤销途中意外失败即停，记录已恢复及未恢复，后续可重试剩余项。撤销本身也必须先写 intent 后写 done，支持中断核对。重复撤销已完成批次是 no_op，不影响文件。
撤销只保证原相对路径与文件内容恢复，不承诺恢复目录时间、ACL、扩展属性等全部元数据。清理本工具创建的空目录；绝不删除执行前已有目录。

四、界面与 CLI
界面四区：Folder & Rules、Preview、Results、History & Undo。选择目录后显示完整根路径，预览用相对路径。冲突时 Apply 禁用；执行中禁用重复提交及规则编辑；不提供无法可靠实现的强制取消按钮。错误用英文短句解释原因及下一步。
CLI 语义：plan ROOT --rules rules.json --out plan.json；apply plan.json --yes；history --root ROOT；undo RUN_ID --yes。命令名可采用 python -m fileorganizer。退出码：0 成功/no_op，2 参数/预检失败且未移动，3 执行或撤销中途失败/需恢复，1 未预期异常。标准错误不得只留下不解释原因的 traceback。

五、必须通过的验收用例
所有文件操作测试只在临时沙盒中运行。每项提供测试文件/测试名、实际结果、证据，不得仅勾选“通过”。
A01 默认只扫描第一层；递归开关正确；扩展名筛选大小写不敏感。
A02 中文、空格、多点文件名、无扩展名、零字节文件可正确处理。
A03 替换/前后缀/编号组合符合固定顺序；排序稳定；1000个文件编号不重复或截断。
A04 按扩展名分类及 no_extension 正确，原扩展名保留。
A05 修改年月采用 UTC；用月末跨时区边界的固定 mtime 验证。
A06 不分类保留父目录；分类展平后产生的同名冲突被识别。
A07 预览前后源树路径/文件SHA-256一致，且未创建 Organized。
A08 同规则重复生成映射相同；无规则或无文件得到可解释 no_op。
A09 现有目标和批次内同名均阻止整个执行，所有源文件不动。
A10 Windows 保留名、非法字符、尾点空格、大小写冲突/仅大小写改名均阻止。
A11 交换及循环映射拒绝；父路径为文件拒绝；长路径不支持时明确预检失败。
A12 ../、绝对目标、不同卷、链接/junction、硬链接和被篡改计划不能绕过边界。
A13 预览后修改源内容（含相同大小）、删除源、替换源身份或创建目标，apply 零移动。
A14 改规则后旧预览失效，不能直接点击执行；双击/多实例不能重复移动。
A15 正常执行的每项目标路径和SHA-256符合计划；no_op/skipped 不变。
A16 移动前最后一刻插入目标文件，验证不会覆盖它；报告部分失败并停止。
A17 注入第N项权限/占用/移动失败：此前成功可核对，其后未执行，日志和计数一致。
A18 日志目录不可写时零移动；中途日志故障停止后续操作并可恢复核对。
A19 子进程在 intent 后、移动后 done 前、done 后被终止，重启均准确核对；歧义转 needs_review，不猜测。
A20 正常撤销后全部原相对路径和SHA-256恢复；只清理本批新建空目录。
A21 撤销前目标被改/替换/丢失或原位置被占用，整次拒绝，现有文件均不动。
A22 部分执行批次仅撤销成功项；重复撤销无副作用；拒绝越过最近批次撤销旧批次。
A23 撤销第N项失败/进程中断：保留日志，可核对并重试剩余项，不重复操作已恢复项。
A24 两个本工具实例竞争同一根目录，只允许一个执行；进程异常退出后锁可释放。
A25 CLI 与 UI 使用相同核心，同快照规则得到相同映射与结果；错误退出码正确。
A26 新目录干净安装、运行演示、完整测试通过；记录 Windows/Python/依赖版本和提交SHA。
A27 实际界面操作完成选择→预览→执行→撤销，截图、日志和磁盘真实状态吻合。
Windows 专属用例必须在真实 Windows 运行；其他系统通过不能替代。需要权限才能制造的场景应说明环境；未运行不得声称通过。
