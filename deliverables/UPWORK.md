Safe File Organizer: Preview, Apply and Undo (Python)

## Project description

Personal demo project with synthetic data, not client work. A Windows desktop tool (Python, tkinter) and command line that renames and sorts files by extension or month. It shows a preview first, blocks any plan where two files map to one target, never overwrites, and writes a journal before and after every move. One click undoes a run; the demo restores 36 of 36 files with identical SHA-256. Includes 159 automated tests and a recorded real-window run.
